# Student Grade Calculator

## About the Project
Student Grade Calculator is a simple Java-based console application that calculates the total marks, average percentage, and grade of a single student based on the marks entered in different subjects.

Currently, this program calculates results for only one student at a time.

## Features
- Takes the number of subjects as input.
- Accepts marks for each subject out of 100.
- Calculates total marks.
- Calculates average percentage.
- Assigns a grade based on average percentage.
- Displays the final result.

## Technologies Used
- Java
- Scanner Class
- Conditional Statements (if-else)
- For Loop
- OOP Concepts

## Grading System
- Below 32% : D (Fail)
- 32% to below 50% : C
- 50% to below 75% : B
- 75% to below 90% : A
- 90% and above : A+

## How to Run
1. Clone or download this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java file.
4. Run the program.
5. Enter the number of subjects and marks when prompted.
